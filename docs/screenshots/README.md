# Screenshots

Put the README screenshots here, using these file names:

| File | What to capture |
|---|---|
| `01-welcome.png` | The open-file screen |
| `02-overview.png` | Overview tab with a loaded APK (summary strip, findings, attack surface) |
| `03-findings.png` | Security tab with a finding selected (detail panel visible) |
| `04-manifest.png` | Manifest tab |
| `05-code-editor.png` | The decompiled code editor window |
| `06-report-pdf.png` | First page of an exported PDF report |
| `07-settings.png` | Settings window |

Tips: use a window of about 1280×820, keep the light theme for consistency, and avoid APKs whose contents
you don't want published — screenshots show package names, file paths and masked secrets.
